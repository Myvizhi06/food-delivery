## 🍔 Key Features

1. **Category Navigation & Filtering**:
   - Filter across Burgers, Pizza, Asian & Sushi, Healthy Bowls, Desserts, and Beverages.
2. **Real-Time Food Search**:
   - Live search bar instantly filters dishes by title, description, or restaurant name.
3. **Interactive Cart Drawer**:
   - Slide-in side cart with item count, quantity adjusters (`+` / `-`), and remove button.
   - Calculates Subtotal, Tax (8%), and Delivery Fee (Free on orders over $30).
   - Promo coupon system: enter `CRAVE30` for an instant 30% discount.
4. **Checkout & Order Tracking Modal**:
   - Delivery address and payment method form.
   - Order confirmation with randomized Order ID and visual delivery step progress.
5. **Local Storage**:
   - Saves current cart and applied coupon so cart items survive page refreshes.
6. **Responsive Design**:
   - Mobile, tablet, and desktop optimized with sticky navigation and clean animations.
